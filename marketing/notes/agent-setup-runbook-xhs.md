## 文案 A

**标题：** 让 AI 干活前，先写这四件事

**正文：**
Agent 跑偏，多数不是模型不行，而是任务没写清。

给 Agent 派活前，先写一页运行手册：

1. 任务：输入、输出、验证方式
2. 边界：可读、可写、可执行
3. 停止规则：两次失败就停
4. 复核记录：谁看过、证据是什么

不用复杂框架，一页就够。

免费模板放评论。
