# Payment QR assets

Upload the two QR images here using these exact filenames:

- `alipay-qr.png` — Alipay personal or merchant collection code
- `wechat-qr.png` — WeChat Pay personal or merchant collection code

After uploading to `main`, GitHub Pages will display them automatically at `/payment.html`.

Do not upload screenshots containing full names, phone numbers, ID numbers, bank cards, or other sensitive data unless the details are intended to be public.
