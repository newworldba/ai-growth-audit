# AI Agent 配置帮助 — 交付手册

这个模板用于一次 45 分钟工作会话，只配置一个可重复工作流。不要虚构工具、结果或客户案例；访问任何非公开系统前必须先获得授权。

## 会前闸门

1. 确认请求适合一次 45 分钟会话。
2. 确认客户可以旁观、批准并随时停止配置。
3. 确认不需要密码或密钥；如果必须使用，先停止并改变方案。
4. 记录：
   - 谁会使用工作流。
   - 重复任务是什么。
   - 当前工具是什么。
   - 期望输出是什么。
   - Agent 不能做什么。

## 45 分钟议程

| 时间 | 重点 | 产出 |
|---|---|---|
| 0-5 分钟 | 确认任务和成功标准。 | 一句话说明输入和输出。 |
| 5-15 分钟 | 定义安全边界。 | 允许 / 需询问 / 禁止 清单。 |
| 15-35 分钟 | 配置最小可用工作流。 | 用一个示例跑通。 |
| 35-42 分钟 | 和客户一起写运行手册。 | 命令、提示词、限制和下一步。 |
| 42-45 分钟 | 约定检查点。 | 一个跟进动作和时间。 |

## 质量检查

- 工作流跑通了一个真实或代表性示例。
- 客户能说明输入、输出和停止规则。
- 没有索取密码、密钥、证件、支付信息或未授权数据。
- 运行手册控制在一页内。
- 客户知道如何停止或撤销工作流。

## 跟进

24 小时内发送一页运行手册。只有当客户提出新的工作流，或已测试工作流需要实质不同的配置时，才推荐第二个付费会话。
