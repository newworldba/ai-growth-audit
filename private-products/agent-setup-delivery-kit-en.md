# AI Agent Setup Help — delivery kit

This template supports one 45-minute working session for one repeatable workflow. Do not invent tools, outcomes, or case studies. Ask before accessing any non-public system.

## Pre-session gate

1. Confirm the request fits one 45-minute session.
2. Confirm the client may watch, approve, and stop the configuration at any time.
3. Confirm no credentials are required. If credentials are required, stop and change the approach.
4. Record:
   - Who uses the workflow.
   - The repeating task.
   - Current tools.
   - Required output.
   - What the agent must not do.

## 45-minute session agenda

| Time | Focus | Output |
|---|---|---|
| 0-5 min | Confirm the task and success test. | One sentence describing input and output. |
| 5-15 min | Define safety boundaries. | Allow / ask / never list. |
| 15-35 min | Configure the smallest working workflow. | A tested run for one example. |
| 35-42 min | Write the runbook with the client. | Commands, prompts, limits, and next step. |
| 42-45 min | Agree the next checkpoint. | One follow-up action and date. |

## Quality checks

- The workflow completed one real or representative example.
- The client can explain the input, output, and stop rule.
- No credential, secret, identity document, payment information, or unauthorized data was requested.
- The runbook is one page or fewer.
- The client knows how to stop or undo the workflow.

## Follow-up

Send the one-page runbook within 24 hours. Offer a second paid session only if the client has a new workflow or the tested workflow needs a materially different setup.
