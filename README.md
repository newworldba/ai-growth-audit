# AI Growth Audit Launch Kit

This is a fixed-scope service package for selling website conversion audits to founders and small teams.

## Live site

<https://newworldba.github.io/ai-growth-audit/>

## Publish

This repository publishes `index.html` to GitHub Pages with the workflow in `.github/workflows/pages.yml`.

After pushing to `main`:

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Set **Source** to **GitHub Actions**.
4. Run or rerun the **Deploy site to GitHub Pages** workflow if needed.

## Contents

- `index.html` — public landing page.
- `zh/index.html` — Chinese landing page for Alipay and WeChat clients.
- `.github/ISSUE_TEMPLATE/audit-request-zh.yml` — Chinese client intake form.
- `sample-report.html` — anonymized sample report format.
- `payment.html` — Alipay and WeChat Pay order flow for RMB invoices.
- `.github/ISSUE_TEMPLATE/audit-request.yml` — structured client intake form.
- `offer.md` — packages, scope, delivery workflow, and legal guardrails.
- `lead-magnet.md` — downloadable checklist for collecting leads.
- `cold-email-sequence.md` — four-email outreach sequence.
- `outreach-plan.md` — target profiles and daily outreach routine.
- `launch-checklist.md` — setup, launch, delivery, and weekly review checklist.

## Legal Position

The service provides analysis and recommendations only for pages the client owns or authorizes. It does not promise revenue, use unauthorized access, or rely on platform-policy circumvention.
