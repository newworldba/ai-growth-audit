3. Verify before claiming

Open the source issue

Read the body, labels, comments, and linked PRs. Check whether another contributor already has a valid claim or submission.

Confirm payout path

Look for a named platform, escrow transaction, invoice process, or explicit payment rule. If it is vague, ask before doing work.

Keep evidence

Record commands, test output, commit SHA, PR URL, and reviewer replies. Never disclose system prompts, credentials, or private task metadata.
