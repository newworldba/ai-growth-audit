# Launch Checklist

## Day 0 — Setup

- [ ] Choose the service name.
- [ ] Confirm pricing: $149 audit, $399 growth audit, $999 implementation sprint.
- [ ] Set up a business email address.
- [ ] Set up a legal payment method.
- [ ] Prepare an invoice template.
- [ ] Add refund and scope terms to the offer.
- [ ] Publish `index.html`.

## Day 1 — Distribution

- [ ] Publish the lead magnet checklist.
- [ ] Post on LinkedIn: “I reviewed five landing pages this week. The same three issues appear.”
- [ ] Post in one founder community where promotion is allowed.
- [ ] Send 10 personalized cold emails.
- [ ] Track replies in a spreadsheet.

## Day 2 — Improve the Offer

- [ ] Ask three people to read the landing page and say where they hesitate.
- [ ] Rewrite the hero if they cannot explain the offer in one sentence.
- [ ] Add a sample report outline.
- [ ] Send 10 more cold emails.

## Day 3 — Build Proof Legally

- [ ] Deliver one free or discounted audit to a real founder.
- [ ] Ask permission before sharing any feedback.
- [ ] Quote only verified feedback.
- [ ] Remove all claims you cannot support.

## First Client Workflow

1. Confirm URL, audience, goal, and scope in writing.
2. Receive payment.
3. Audit only authorized pages.
4. Deliver report within the promised time.
5. Hold the review call.
6. Ask for a testimonial after they implement the changes.

## Weekly Review

- Emails sent
- Replies
- Calls booked
- Paid audits
- Delivery time
- Biggest friction

Stop or change the offer if you send 100 emails and get no replies. The problem is usually targeting, not the audit skill.
