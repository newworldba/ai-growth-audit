# 任务运行手册

## 任务
- 目标：修改一个模块 / 生成一份报告 / 总结一个资料源。
- 输入文件：`src/example.py`、`docs/brief.md`
- 期望输出：`docs/output.md`
- 验证方式：`npm test` / `python script.py --check`

## 安全边界
- 可读：只读上面列出的文件。
- 可写：只写期望输出文件。
- 可执行：只执行验证命令。
- 需要先确认：删除文件、安装依赖、发送消息。
- 禁止：密码、客户数据、生产系统。

## 停止规则
- 同一问题连续失败两次后停止。
- 任务超出列出的文件范围后停止。
- 无法展示验证输出时停止。
