网站转化自查清单：25 个关键检查项

适合独立站、SaaS、课程页、咨询服务网站。逐项标记“良好 / 需改进 / 缺失”，就能快速找到最大漏点。

1. 定位清晰

  1. 首屏说明产品是给谁用的。
  2. 首屏说明用户能得到的实际结果。
  3. 标题避免“创新”“强大”“下一代”等抽象词。
  4. 首屏有主要 CTA。
  5. 页面只有一个明显的下一步。

2. Offer 清楚

  1. 访客知道购买或注册后会得到什么。
  2. 价格或价格流程容易找到。
  3. 页面说明谁不适合买。
  4. 至少处理一个常见顾虑。
  5. CTA 描述具体动作，而不是“提交”。

3. 信任感

  1. 页面说明背后是谁或哪个团队。
  2. 使用具体证明，而不是只有“好评很多”。
  3. 客户评价描述使用场景，而不只是夸产品。
  4. 联系方式容易找到。
  5. 退款、取消或支持政策可见。

4. 页面结构

  1. 每个板块只回答一个问题。
  2. 手机端不需要缩放也能阅读。
  3. 主要 CTA 在关键决策点重复出现。
  4. 避免大段文字。
  5. 表单只要求必要信息。

5. SEO 基础

  1. 标题标签说明页面主题和目标客户。
  2. Meta description 说明收益并引导点击。
  3. 主标题匹配页面意图。
  4. 内链帮助用户到价格、文档或联系页。
  5. 图片有有用 alt，并且不会拖慢首屏。
