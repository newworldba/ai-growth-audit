# 第三批近 30 天目标网站

更新时间：2026-10-21  
来源：Hacker News Algolia API 的近 30 天 Show HN 结果。目标页当日均返回 HTTP 200。发送前仍需重新确认在线状态，且必须等待用户明确确认后才可发送。

## 选择逻辑

- 优先选择有公开产品页的独立 SaaS、开发者工具或免费转付费工具。
- 参考页面是否包含 pricing、注册、联系等信号。
- 保留公开讨论区中的真实用户问题，作为触达观察依据。
- 不承诺收入，不群发，不伪造关系。

## 使用规则

1. 每天最多 5 条首次触达。
2. 发送前重新访问目标网站，确认页面仍然在线、定位未变化。
3. 把表中的角度改写成一条具体观察，不要复制同一封模板。
4. 第一次触达只争取回复；两次无回复即停止。
