# 10 个自主找到的潜在客户

来源：GitHub 公开仓库、README 与项目主页。以下只是初步线索，发送前应先打开网站确认当前状态，不要复制模板时写错项目名。

## 筛选标准

- 最近活跃的独立产品 / 小型 SaaS。
- 有公开网站或项目主页。
- 现阶段很可能需要转化、获客或页面优化。
- 优先选择创始人或小团队，而不是大型企业。

## 触达节奏

1. 每天最多联系 5 个，避免一次性发完。
2. 先打开网站确认仍然存在、仍在运营。
3. 私信或邮件里不要说“我看了你的网站很好”，要写一个具体观察。
4. 第一条信息只争取回复，不争取付款。
5. 有回复后再发申请表：<https://newworldba.github.io/ai-growth-audit/zh/apply.html>

## 首次触达模板

```text
Hi {{name}},

我在 GitHub 上看到 {{product}}。第一眼理解是：{{one_line_summary}}。

我通常会检查一个点：{{specific_angle}}。

如果这对你们现在有帮助，我可以先做一次 48 小时审计，给出 Top 10 修复项。固定价格 ¥1,080 起。

需要我先发申请表吗？
```

## 跟进模板

```text
Hi {{name}},

补充一个具体建议方向：{{one_specific_observation}}。

如果这个点也是你们关心的问题，48 小时审计可以把类似问题整理成一份可执行清单。
```

## 停止条件

- 对方明确说不需要。
- 对方表示已经有设计师 / 顾问处理。
- 两次跟进无回复。
